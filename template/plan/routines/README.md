# Routine template

Each routine is one file named `<location>-<name>.md`. The table layout mirrors
Xunji's template screen so it can be copied into the app line by line.

```markdown
# <Routine name>

**Location:** Gym · **Duration:** ~60 min · **Last updated:** YYYY-MM-DD

## Changes (since last version)
- Bench press: 60 → 62.5 kg
- Swapped cable fly for DB fly (cable station usually busy)

## Warm-up
- 5 min bike, then ramp sets listed below

| # | Exercise (Xunji name) | Sets × Reps | Load (kg) | RPE | Rest |
|---|---|---|---|---|---|
| 1 | Barbell Bench Press 杠铃卧推 | warm-up 20×10, 40×5, 50×3 | | | 1:00 |
| 1 | Barbell Bench Press 杠铃卧推 | 3 × 6–8 | 60 | 7–8 | 2:30 |

## Notes
- Cues, substitutions, what to do if equipment is taken.
```

Keep the Chinese exercise name next to the English one so it matches what
Xunji shows and what the importer sees in exports.
