# Fitness data (private)

Personal data for the [fitness-coach](https://github.com/RitterRen/fitness-coach)
system: profile, medical history, plan, routines, logs and reviews.

**Keep this repository private.** Clone it into `private/` inside your
fitness-coach checkout; the scripts and Claude Code skills there read and
write these files.

- `profile/` — stats, medical history, goals
- `plan/` — current program and routines (copy into Xunji)
- `data/` — weight, strength (Xunji), cardio (Strava), nutrition and mood (Muse)
- `inbox/xunji/` — raw Xunji exports
- `reviews/` — session and weekly reviews
- `docs/muse-data-contract.md` — what Muse may write, and in what format
